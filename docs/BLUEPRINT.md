# serial-split 蓝图

> 正文描述当前已落地的行为；历史原因见 CHANGELOG.md。
> 重写时保留这里的行为和数据契约，未列为硬约束的实现细节可以自由更改。

## 用途

Windows 桌面串口分路器：让协议模拟器、串口助手等多个软件同时使用一个物理串口，并按需把经过物理口的数据录入 SQLite。com0com 虚拟口对的 A 端给这些软件使用，B 端由本程序使用。

## 分组与转发

- 新建分组后，可配置名称、物理口、波特率、数据位、校验位、停止位、多个虚拟口和是否录制；默认 2400 8N1、开启录制。改动立即保存，重启后恢复。
- 一个虚拟 A 端只能属于一个分组；被其他分组选中的口置灰并显示所属分组。不同物理口的分组可同时运行，同一物理口不能被两个运行中的分组占用。
- 打开分组后，物理口收到的字节原样发给所有选中的虚拟口；任一虚拟口发送的字节写进物理口。多个发送者可以交错，不增加协议解析或请求仲裁。
- 软件没有打开虚拟 A 端或不读取时，该端来不及接收的数据可以丢弃并累计丢弃字节数，其他端继续工作。虚拟口发向物理口的命令不会因待发送队列满而直接丢弃。
- 物理口写超时或返回零时，显示未确认字节警告，不自动重发这些字节；TX 录制以实际成功写出的字节为准。
- 运行时参数控件锁定，运行中的分组不能删除。停止后解除锁定；停止过程显示“停止中”。
- 物理口未连接、被占用或运行中发生读写故障时，显示原因并每 3 秒重试，直到恢复或用户停止。退出保留分组的运行意愿，下次启动自动恢复；用户主动停止会取消自动恢复。

## 界面与窗口

- 使用紧凑的工业上位机风格、系统标题栏和中文标签，窗口标题为“串口分路器”。顶部标签切换分组，“＋”新建并切换；双击标签可以改名、删除或取消。
- 默认数据区收起，逻辑尺寸为 300×334；展开为 780×334，展开后允许拉大，收起恢复固定大小。展开状态和浅色／深色主题会保存。
- 物理口下拉展开时刷新，显示端口名及可用的 USB 描述；蓝牙、虚拟口有相应标注。已保存但当前不存在的口显示“未连接”，不会冲掉原选择。虚拟口复选框两列排列，可滚动访问更多口；未检测到虚拟口对时显示红色提示。
- 底栏显示状态、物理口 RX／TX 字节数和所有虚拟口丢弃字节总数，均为纯数字。运行中展开数据区可见运行时长；点击等待或错误状态可在数据区查看完整原因。
- 数据区按分组保存最近 2000 行，超过时淘汰最旧行。暂停只冻结显示，转发和录制继续；恢复时显示当前保留的数据。可切换自动滚动、清空及 HEX／文本显示，显示模式切换只影响随后到来的行。
- 数据行包含本地时间 `[HH:MM:SS.mmm]`、方向和内容；TX 带 `TX←<虚拟A端名>`。HEX 按十六进制显示前 64 字节，超出部分标注 `…(+<剩余字节数>)`，录制仍保存完整数据；文本用 UTF-8 有损解码，控制字符（含换行）显示为 `.`。提示为绿色、错误为红色、TX 为蓝色、时间戳为灰色，深色主题有对应配色。
- 设置窗可修改主题、关闭动作、保留天数和开机自启，管理虚拟口对并打开数据目录。“软件用／本程序用／分组”三列共用一致列宽。

## 虚拟口检测与管理

- 从 com0com `Parameters` 和 Windows `SERIALCOMM` 注册表信息合并口对，按序号排序；名称优先采用 Parameters 的 `PortName`，没有时使用 `CNCA<n>`／`CNCB<n>` 默认名。即使 B 端不在 SERIALCOMM 中，也保留由 A 端确认的口对。
- B 端隐藏状态取自 `Parameters\CNCB<n>\HiddenMode`：字符串 `yes`（不区分大小写）或 DWORD `1` 为隐藏，缺省或其他值为未隐藏。无 `PortName` 的 B 端子键仍可检测。
- 普通物理口列表排除 com0com 的 A、B 两端；测试参数 `--include-virtual` 允许把 A 端作为假物理口，仍不列 B 端。
- 新建口对校验 A 端名字、拒绝已存在的明确名字；建议可用 COM 名，也接受 `COM#` 让驱动分配。调用契约为 `setupc --silent install PortName=<名字> HiddenMode=yes`，新建时自动隐藏 B 端。
- 存在未隐藏 B 端时，设置窗显示“隐藏本程序端”；点击后一次提权批量对这些端执行 `setupc --silent change CNCB<n> HiddenMode=yes`，结束后重新检测。全部隐藏时不显示按钮，列表不增加隐藏状态列。
- 删除被分组使用的口对会被拒绝；其他口对通过 `setupc --silent remove <n>` 删除。管理操作在 setupc 所在目录运行，等待 Windows 提权确认，取消显示“已取消”，结束后重新检测；缺少 setupc 时提示“没装 com0com”。
- 隐藏使用驱动的 HiddenMode 能力，目的是让本程序的 B 端尽可能不被其他串口软件枚举；具体枚举器是否尊重隐藏由驱动及外部软件决定。

## 录制与数据契约

- 勾选录制后，每次成功打开物理口产生一个 session，录入 RX 和成功写出的 TX 原始字节；停止、退出或故障补写结束时间和原因。
- 数据库为 `%LOCALAPPDATA%\serial-split\capture.sqlite3`，采用 SQLite WAL，其他程序可在录制期间只读查询。数据库写入失败会在界面显示错误，转发继续；录制数据不得静默丢弃。
- 下次启动时，把没有结束时间的旧 session 补记为“程序异常退出”；结束时间取最后一条 chunk 时间，没有 chunk 则取开始时间。
- 默认保留 30 天，启动时和之后每 6 小时清理过期 chunk，以及已结束且没有 chunk 的过期 session。

| 表 | 列与含义 |
|---|---|
| `sessions` | `id` 整数主键；`group_name`、`port`、`line_settings`、`outputs`、`started_at` 为必填文本；`ended_at`、`end_reason` 为可空文本。串口参数如 `2400 8E1`，outputs 是逗号分隔的 A 端名。 |
| `chunks` | `id` 整数主键；`session_id` 必填外键引用 sessions；`utc` 必填 UTC 文本；`mono_us` 必填单调时钟微秒；`direction` 只允许 `RX`／`TX`；`source` 为可空文本（TX 来源 A 端名，RX 为 NULL）；`raw` 为必填 BLOB。 |

时间文本为 UTC ISO 格式 `YYYY-MM-DDTHH:MM:SS.mmmZ`；同会话间隔可用 `mono_us`。索引为 `chunks_session(session_id,id)` 和 `chunks_utc(utc)`。结束原因包括“用户停止”“程序退出”“物理口故障: <原因>”“程序异常退出”。

配置文件为 `%APPDATA%\serial-split\settings.ini`，UTF-8 文本、键值与分组节格式；保存以临时文件替换，坏值保留默认值，旧配置缺少主题／展开键时仍可读：

```ini
theme=light
show_data=false
close_action=ask
retention_days=30

[group.1]
name=分组1
port=COM6
baud=2400
data_bits=8
parity=none
stop_bits=1
outputs=COM11,COM12
record=true
running=false
```

`theme` 为 `light|dark`，`close_action` 为 `ask|tray|exit`，`parity` 为 `none|even|odd`；正整数分组 ID 唯一，outputs 存 A 端名。开机自启不写入 INI，以注册表为唯一真相。

## 托盘、自启与退出

- 单实例：重复启动唤出已有窗口，然后退出新实例。托盘单击／双击或菜单“显示窗口”显示并置前；菜单“退出”关闭程序，提示文字显示运行分组数。
- 关闭窗口可每次询问、最小化到托盘或直接退出；询问可记住选择或取消。隐藏窗口后继续转发和录制；退出时停止所有分组、提交剩余录制数据并保存设置。
- 自启值为 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\serial-split`，内容为 `"<当前exe绝对路径>" --minimized`。勾选直接读写注册表；已开启但路径改变时启动修正。`--minimized` 启动仅显示托盘。

## 边界与硬约束

- Windows 原生桌面、单 exe 交付，虚拟口依赖已安装的 com0com 驱动；不依赖 hub4com、不自写驱动、不改成 TCP 串口替代方案。
- 用户显式配置分组和串口参数，不自动接管全部物理口，也不跟随虚拟口使用者设置波特率。不转发 DTR／RTS 等控制线，不承诺为多个软件提供独立设备会话。
- 业务规则与界面、I/O 分离，规则可独立验证；串口访问互不并发争用同一口，慢接收端不能拖住其他接收端；显示丢弃与录制完整性分别处理。
- 本轮隐藏修复已通过纯解析与命令生成单测、无串口 UI 快照检查；一次 UAC 及实际驱动隐藏效果未在本轮执行验证。
- **以上未列出的一切均为实现细节，重构可自由更改。**
