# 任务书：serial-split v2 界面改版

给执行者（codex）。v1 功能已实现并经主聊实机联调通过（双向转发、SQLite 录制、异常退出补记、物理口被占时等待重试），代码已提交在 `feat/v1`。用户看了 v1 界面说"太丑"，经三轮样稿确认了新界面。**这次只改界面，转发/录制/检测/托盘/注册表等行为不变。**

用户确认的样稿：`docs/ui-mockup.html`（在浏览器里打开即可看；按 1:1 像素画的）。用户已确认的约定见 `docs/HANDOFF.md`「已谈定」，冲突时以它为准。

## 1. 风格：工业上位机（串口调试助手那一路）

用户原话："还是不够紧凑，工业上位机风格"、"只是个基础的虚拟串口工具，我要小一点"。照样稿做，要点：

- 浅灰窗体底色 `#f0f0f0`，正文 12px "Microsoft YaHei"，数据区 12px "Consolas"。
- 分组框（GroupBox）：细边框 + 左上角蓝色标题文字压在边框上（样稿的 `fieldset/legend`）。
- 标签 + 下拉框一行一项，列宽对齐；控件高度约 20px（下拉框白底、1px 深灰边、右侧带小下拉按钮区）。
- 按钮方角、浅灰渐变、约 24px 高；默认按钮蓝色描边。
- 圆形指示灯（LED）：绿=运行，灰=停止，红=出错或等待重试。
- 底部分格状态栏（每格凹陷边框）。
- **不要用 std-widgets 的 Fluent 控件**（太高太圆，正是"丑"的来源）。在 `slint!` 里自己写一套小组件：`GroupBox`、`ClassicButton`、`ClassicCombo`（用 `PopupWindow` 弹出列表，支持键盘上下选择更好但不强制）、`ClassicCheck`、`Led`、`TabItem`、`StatusCell`、`ClassicInput`（基于 `TextInput`）。ListView/ScrollView 可以继续用 std 的做滚动容器，但外观要和整体一致。

## 2. 窗口与布局（数字都是逻辑像素）

### 2.1 默认：数据区收起，300 × 334
自上而下：
1. 系统标题栏（用系统的，不自绘）。标题"串口分路器"。
2. **分组标签页**：每个分组一个标签，标签内左侧 LED + 分组名；最后一个"＋"标签 = 新建分组并切换过去。**双击标签** → 弹出小窗：名称输入框、"删除分组"按钮（运行中置灰）、"确定/取消"。
3. "物理口"分组框，4 列网格（标签 52 / 控件 / 标签 44 / 控件）：
   - 端口号：下拉跨三列，显示 `COM6 USB-SERIAL CH340` 这类（端口名 + 描述；描述没有就只显示端口名；保留 v1 的"（未连接）""（蓝牙）""（虚拟）"标注）；下拉弹出时自动刷新一次端口列表（取代 v1 的"刷新"按钮）。
   - 波特率 / 校验位（None / Odd / Even）；数据位（8 / 7）/ 停止位（1 / 2）。
4. "转发到虚拟口"分组框：复选框两列网格，显示 A 端名（COM11…）；被别的分组占用的置灰并在名字后加小号灰字分组名。没检测到 com0com 时框内显示一行红字"没检测到 com0com 虚拟口对"。
5. 两个并排按钮：左"打开串口 / 关闭串口"（内嵌 LED，默认按钮样式），右"显示数据 >>"（展开时为"<< 收起"）。
6. "录制到数据库"复选框。
7. 状态栏：`状态 | RX:<字节数> | TX:<字节数> | 丢:<丢弃字节数>（伸缩）| 设置`。状态文字：运行中（展开时附运行时长 HH:MM:SS）/ 已停止 / 等待重试 / 停止中；等待重试和错误时状态格红字，悬停或点击状态格可看完整原因（tooltip 或在数据区打一行，二选一）。"设置"格可点击。RX/TX 是纯数字（不换算 KB），丢 = 所有虚拟口丢弃字节之和。
   - 运行中参数控件全部置灰（v1 已有的 locked 逻辑沿用）。

### 2.2 展开：780 × 334（窗口宽度随之变化，收起时缩回 300）
- 左侧 290 宽保持不变；右侧"数据"分组框：白底等宽接收框 + 下方工具行（"暂停""自动滚动""HEX"三个复选框，右侧"清空"按钮）。
- 行格式：`[HH:MM:SS.mmm] TX←COM11 FE FE …` / `[HH:MM:SS.mmm] RX 68 20 …`；提示行绿色、错误行红色、TX 蓝色 `#0000c8`、RX 黑色、时间戳灰色。HEX 取消勾选 → 按文本显示（UTF-8 有损解码，控制字符显示为 `.`，`\r\n` 不换行显示为 `.`），切换只影响之后新到的行即可。
- 展开后窗口可以拉大（数据区跟着变大）；收起后宽度固定 300、不可横向拉伸，高度可固定 334。
- 展开/收起状态写进 settings.ini（全局键 `show_data=true|false`），启动时恢复；默认 false。

### 2.3 设置窗（点状态栏"设置"）
做成窗口内的模态弹层，或单独 Slint 窗口，二选一（单独窗口更像上位机，推荐）。约 300 宽：
- "常规"分组框：外观（浅色 / 深色）、关闭窗口时（每次询问 / 最小化到托盘 / 退出程序）、数据保留（天，数字输入或下拉 7/15/30/90/180/365）、开机自启复选框。
- "虚拟口对（com0com）"分组框：表格列表（软件用 / 本程序用 / 分组），可选中一行；按钮"新建""删除""数据目录"。"新建"弹一个小输入框（默认 `core::suggest_port_name`），沿用 v1 的 setupc 提权逻辑和消息。
- 右下"确定"关闭。

### 2.4 关闭询问
改成同风格的小对话框：文字"关闭窗口时："、按钮"最小化到托盘""退出程序""取消"，复选框"记住我的选择"。行为与 v1 相同。

## 3. 主题

- 默认浅色（上面的颜色）。设置里可切"深色"：窗体 `#2b2b2b`、控件底 `#1e1e1e`、文字 `#dcdcdc`、边框 `#555`、分组标题 `#6cb6ff`、数据区底 `#1e1e1e`、TX `#6cb6ff`、RX `#dcdcdc`；LED 颜色不变。
- 颜色全部集中在一个 Slint `global Theme { }` 里，用一个 `dark: bool` 切换，组件只引用 Theme 的属性。
- 主题写进 settings.ini（全局键 `theme=light|dark`），默认 light。

## 4. 配置文件改动（core.rs）

- `Settings` 增加 `theme`（枚举 Light/Dark）和 `show_data: bool`，`parse_settings` / `format_settings` 支持，坏值回默认；补单测（含旧版没有这两个键的 ini 能正常读）。
- 文本模式显示行：在 core 里加一个纯函数（如 `display_text_line`），带单测。
- `core.rs` 已有测试断言不许改。

## 5. 不变的东西

- bridge.rs / recorder.rs / c0c.rs / winsys.rs / tray.rs 的行为不变；只有为了给界面提供数据（如端口描述、运行开始时间）才可以加只读接口。
- 单实例、托盘、开机自启、`--minimized`、`--include-virtual`、分组自动恢复与 3 秒重试，全部保持。
- 每个分组最多保留 2000 行显示，暂停/清屏语义不变。
